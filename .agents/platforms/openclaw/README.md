# OpenClaw 2.x — Setup for Gamukis Repository

Status: Compiled from OpenClaw documentation (releases 2026.8.x–2026.9.x). Not yet verified on a live OpenClaw installation; run the smoke test in `../../PLATFORMS.md` following setup.

## What You Need to Know

- The default OpenClaw workspace is `~/.openclaw/workspace`, not the repository itself. Agent file manipulation tools only operate inside the workspace.
- `AGENTS.md` in the workspace is loaded each turn. Therefore, the repository's `AGENTS.md` is kept concise.
- Skills are discovered in `<workspace>/skills`, then `<workspace>/.agents/skills`, `~/.agents/skills`, and `~/.openclaw/skills`. If the workspace is configured to point directly to this repository, `.agents/skills/` is discovered immediately, including when added after the Gateway is running (since version 2026.8.2).
- `openclaw setup` / `onboard` generates missing bootstrap files (`SOUL.md`, `IDENTITY.md`, `USER.md`, `HEARTBEAT.md`, `BOOTSTRAP.md`, `MEMORY.md`, `memory/`). Ensure these personal files are excluded from Git.

## Setup Steps

1. Append the contents of `gitignore.snippet` into the repository's `.gitignore`.
2. Direct the workspace to this repository in `~/.openclaw/openclaw.json`:
   ```json5
   { agents: { defaults: { workspace: "<path-to-repo>/gamukis" } } }
   ```
   If you also use OpenClaw for other projects, configure a distinct profile/agent with its own isolated workspace. Configuration key names differ across versions; consult your specific version documentation before configuring.
3. Optional: Copy `TOOLS.md` to the repository root for local command reference. This file does not configure active tools; it is purely informational documentation.
4. Launch a new session and execute the smoke test.

## Recommended Roles

There is no prior OpenClaw task history in this repository. Begin by assuming Analyst/Reviewer or Operator roles (running scheduled verifications, summarizing status) and allow the lead to elevate roles via explicit dispatches. All records must be logged into `.agents/teamwork/` signed as `openclaw · <model> · <date>`.

## Prohibitions

- Do not place skills generated by OpenClaw Skill Workshop into `.agents/skills/` without formal review; such skills belong in the agent's private collection.
- Never store channel tokens (Telegram, Slack, etc.) or API keys inside the repository or in handoff files.
