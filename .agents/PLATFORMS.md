## What Is Used vs. Deliberately Omitted

- **Used:** `AGENTS.md` as the universal entry point for all platforms; `.agents/skills/` as the single canonical source of truth for skills; `.github/instructions/` because `applyTo` pattern matching is supported by Copilot.
- **Omitted: `.agents/rules/`.** Antigravity loads this directory, but its contents duplicate `AGENTS.md` which is already loaded. Use only if a rule is strictly exclusive to Antigravity.
- **Omitted: `.agents/workflows/` and `.github/prompts/`.** Skills can be directly invoked as slash commands on platforms that support them.
- **Skill Mirrors:** `.github/skills/` is generated by `node scripts/agents.mjs sync`. Do not edit mirrored files directly. `check` detects discrepancies.

## Rules for Writing Portable Skills Across All Platforms

- One folder per skill: `.agents/skills/<name>/SKILL.md`.
- Frontmatter must contain only `name` and `description`, each on a single line. OpenClaw supports only single-line keys.
- `name`: lowercase alphanumeric with hyphens; must match the parent folder name exactly.
- `description`: a single concise sentence specifying when the skill should be invoked. This is the only metadata read by agents prior to loading the full skill.
- Keep body content under 500 lines; place extensive references in separate files and link to them from `SKILL.md`.
- Never place automatically generated agent skills here. OpenClaw Skill Workshop persists auto-generated skills in agent-owned directories outside the repository.

## Known Limitations & Context Budgets

- Antigravity loads both `AGENTS.md` and `GEMINI.md`. `GEMINI.md` is kept to minimal lines to avoid context duplication.
- VS Code indexes both `.agents/skills/` and `.github/skills/`. If duplicate skills appear in the picker, remove the `.github/skills/` mirror (note: Copilot CLI/cloud agent will not see skills without it).
- Codex indexes `.agents/skills/`, `.codex/skills/`, and `.claude/skills/`. Therefore `sync --claude` is optional and disabled by default.
- Duplicate context loads (such as loading `AGENTS.md` and `copilot-instructions.md` simultaneously) waste token budgets.
- If `AGENTS.md` exceeds ~24 KiB, `check` issues a warning because Codex shares a 32 KiB limit across nested files.

## Smoke Testing (Run Once per Platform)

Open a fresh session at the repository root and submit the prompt below. A correct result cites the file content rather than generic advice.

1. "What are the hard project rules regarding score history persistence and the frontend API layer location?" → Must cite `POST /api/players/history` without role permissions and `Frontend/src/database/`.
2. "List all available skills." → Must include `teamwork-dispatch`, `teamwork-handoff`, `teamwork-review`, `gamukis-prd-guard`.
3. Copilot only: open a file in `Backend/` and inquire about backend rules → Must cite `backend.instructions.md`.

If Step 1 fails, the platform did not load `AGENTS.md`; verify the platform's notes in the matrix above.
